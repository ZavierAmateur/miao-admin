# A6E 用户列表资料列审计

## 审计日期

2026-09-20

## 需求

用户管理列表在用户 ID 后增加微信昵称、微信头像和创建时间。

## 契约核对

- 创建时间已有 `createdAt` 字段，可直接展示。
- 后端 P5B7 在列表项增加 `profile`，只包含 `nickName/avatarUrl/updatedAt`；未授权时为 `null`。
- 内部接口仍使用 `/admin/v1/players` 和 `playerId`，不改变路由、筛选、分页或权限。

## 展示规则

- 微信昵称缺失时显示“未授权”。
- 微信头像缺失或无法加载时使用“猫”占位。
- 创建时间使用现有中文日期时间格式。
- 列顺序为：用户 ID、微信昵称、微信头像、创建时间、平台、状态、最近登录、存档版本、操作。

# A6B V1 简易后台总收尾审计

## 审计日期

2026-09-20

## 范围确认

- V1 只服务单管理员、低频内部运维。
- 使用 `npm run dev:cloud` 在开发机启动，通过回环地址代理访问 CloudBase Run。
- 保留登录、玩家查询、玩家详情、存档诊断/回滚、封禁/解封和脱敏错误日志。
- 不建设公网静态托管、HTTP 网关、独立域名、额外容器、管理员管理、复杂监控或工单系统。

## 契约与安全审计

- 页面只访问后端 `/admin/v1/*`，不直连 CloudBase 数据库。
- 请求固定携带 `credentials: include`，不在 localStorage 保存管理员 token。
- 权限由后端强制校验，前端路由和按钮仅改善体验。
- 错误日志不展示请求体、Cookie、Token、存档正文或错误堆栈。
- 高风险写操作保留确认流程；正式玩家不用于破坏性验收。

## 决定

当前功能和交付方式满足 V1，不继续增加部署架构或管理功能。本阶段只做回归检查和总体验收归档。

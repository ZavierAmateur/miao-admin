# A4 精简错误日志接入审计

## 审计目标

- 在现有简易后台增加错误列表和详情，帮助通过 requestId 定位 CloudBase 运行日志。
- 保持 V1 低复杂度，不增加指标仪表盘、告警中心、工单状态、负责人和日志删除功能。
- 以后端 `/admin/v1/errors*` 契约为唯一数据源，浏览器不直连 `admin_error_logs`。

## 页面与字段边界

- 导航新增“错误日志”，仅拥有 `error:read` 权限时显示。
- 列表支持完整 requestId、业务错误码、开始时间和结束时间筛选。
- 列表展示发生时间、业务错误码、HTTP 状态、请求方法、接口模板和 requestId。
- 详情额外展示安全提示、错误类型和日志 ID；不展示请求体、查询参数、Cookie、Token、玩家身份、存档正文或错误堆栈。

## 交互边界

- 默认每页 20 条，通过后端不透明游标翻页。
- 错误详情始终按日志 ID 重新请求，避免把列表缓存误当成完整详情。
- API 失败只展示后端安全中文提示，不在页面输出原始异常对象。

# A3 存档回滚与封禁审计

## 权限与交互

- 存档诊断要求 `save:read`；回滚按钮仅对 `save:rollback` 显示。
- 封禁/解封按钮要求 `player:ban`；运营角色的永久封禁选项禁用。
- 回滚、封禁、解封均通过对话框收集原因；高风险回滚和封禁使用警告说明。
- 回滚提交当前页面 revision，409 时保留页面并要求刷新，避免静默覆盖。

## 数据展示边界

- 存档诊断只展示后端返回的 V1 `user` 白名单字段，不提供任意字段编辑。
- 当前版与上一版展示 revision、版本、保存时间和大小；内部 hash 在 A3B 正式联调时从运营页面移除，字段差异仍明确区分新增、删除与变化。
- 封禁详情展示原因和到期时间，不展示后台内部备注。

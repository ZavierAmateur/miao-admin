# A8 排行榜筛选接入审计

日期：2026-09-22

## 需求

- 闯关榜页面增加微信昵称、平台、用户 ID 筛选字段。
- 查询条件交给后端接口处理，不在浏览器内过滤当前页数据。
- 查询和重置后回到第 1 页，翻页时保留当前筛选条件。

## 接口约定

- `nickName`：昵称关键字。
- `platform`：`wechat` 或 `bytedance`。
- `playerId`：完整用户 ID。
- `page`：当前页，固定每页 20 条。

## 交互约定

- 点击“查询”或在表单中提交时，从第 1 页加载。
- 点击“重置”清空三个条件并重新加载第 1 页。
- 上一页、下一页继续携带三个筛选条件。

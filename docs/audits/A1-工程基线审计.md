# A1 管理后台工程基线审计

## 审计日期

2026-09-18

## 上游基线

- 后端仓库：`miao-travel-server`。
- 后端管理 API：尚未实现 `/admin/v1/*`、管理员认证和 RBAC。
- 已有玩家 API 不得被管理后台当作管理 API 使用。
- 管理会话计划使用 `HttpOnly + Secure + SameSite` Cookie，浏览器不保存管理 token。

## 本阶段范围

- 建立 Vue 3、TypeScript、Vite、Element Plus、Vue Router、Pinia 工程。
- 建立环境配置、统一 API Client、路由鉴权和权限判断边界。
- 提供登录页、后台布局、仪表盘占位、接口状态、403 和 404 页面。
- 管理 API 未冻结前不实现假登录、不虚构玩家数据、不直连 CloudBase。

## 风险与处理

| 风险 | 处理 |
|---|---|
| 前端假登录掩盖后端缺口 | 登录按钮保持禁用并明确提示等待管理 API |
| 管理 token 泄露到本地存储 | API 使用 Cookie 会话和 `credentials: include` |
| 前端权限被当作安全边界 | 文档明确服务端必须逐接口鉴权 |
| 全量引入 Element Plus 导致大包 | 使用自动按需导入，主入口约 111 kB |
| 页面猜测后端字段 | 仅列计划接口状态，不定义未冻结业务 DTO |

## 后续门禁

下一步先在后端冻结管理员认证、会话、RBAC 和 OpenAPI；随后在本仓库接入真实登录、会话恢复、退出及越权测试。A1 的管理员安全验收在真实管理 API 交付前不能标记全部完成。

# A2 玩家查询与接口文档审计

## 页面与权限

- `/players` 和 `/players/:playerId` 均要求 `player:read`，路由守卫继续复用管理员身份中的权限数组。
- 玩家列表只展示 ID、平台、状态、最近登录和云存档 revision，不加载昵称头像。
- 玩家详情只展示后端明确返回的基础信息、资料和云存档摘要，不推断未收集字段。
- `/api-docs` 是后台实际请求契约的只读说明页，不展示密码、Cookie 或其他凭据。

## 交互与失败处理

- 支持完整 playerId 精确搜索、平台/状态筛选和服务端游标翻页。
- 空结果有明确空状态；接口错误展示后端安全消息。
- 头像加载失败由 Element Plus Avatar 文本占位承接，不在浏览器缓存图片副本。

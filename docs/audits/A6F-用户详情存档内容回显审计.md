# A6F 用户详情存档内容回显审计

## 审计日期

2026-09-20

## 需求

在用户详情页面回显当前云存档内容，方便查看用户实际关卡、资产、道具及其他 V1 云存档字段。

## 契约与权限

- 复用现有 `GET /admin/v1/players/:playerId/save`，不新增后端接口。
- 该接口要求 `save:read`；普通 `player:read` 用户不会取得存档正文。
- 详情页基础信息仍由 `GET /admin/v1/players/:playerId` 提供，存档内容加载失败不影响基础信息展示。
- V1 只回显 `modules.user` 白名单字段，不展示 openid、unionid、token、幂等键或本地未上云数据。

## 展示决策

- 关卡、资产、体力、道具、动物和签到状态作为核心进度直接展示。
- 其余字段放入“更多存档字段”折叠区域，保留中文名称和原字段名。
- 提供只读原始 JSON 折叠区域，便于开发排查。
- 当前阶段不允许直接编辑存档；修改、重置或补偿必须使用独立且可审计的后端操作。

## 故障边界

- 无 `save:read` 权限时只显示权限提示，不发起存档诊断请求。
- 存档接口失败时显示独立错误，不清空用户基础资料。
- 用户无云存档时沿用原“暂无云存档”展示。

# A7C 公告状态“启用/停用”术语审计

## 审计结论

- 公告状态的实际业务含义是控制公告能否在游戏端展示，不是内容创作流程中的“草稿/发布”。
- 管理后台应统一使用“停用/启用”，避免管理员把“已发布”误解为一次性的发布动作。
- 后端接口和 CloudBase 已有数据继续使用 `draft/published` 作为兼容值，本阶段不迁移数据库，也不改变已部署接口契约。

## 映射规则

- `draft`：管理后台显示“停用”，游戏端不可见。
- `published`：管理后台显示“启用”；仍需同时满足投放平台、开始时间和结束时间条件，游戏端才可见。
- “自动弹出”是独立设置，不影响公告是否启用。

## 变更范围

- 公告列表筛选项统一为“停用/启用”。
- 公告列表行内状态选择统一为“停用/启用”。
- 公告新增、编辑弹窗及底部提示统一为“停用/启用”。

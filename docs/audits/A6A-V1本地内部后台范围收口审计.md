# A6A V1 本地内部后台范围收口审计

## 审计日期

2026-09-20

## 决策

V1 管理后台只供单管理员低频使用，保持本地内部工具形态。需要使用时在开发机执行 `npm run dev:cloud`，由只监听回环地址的 Vite 代理连接已部署的 CloudBase Run 后端。

## 收口原因

- 当前没有多人异地访问或长期公网运行后台的必要。
- 静态托管、HTTP 网关、独立域名和后端 Origin 配置会增加部署与维护步骤。
- 本地模式已经通过真实 CloudBase 登录、玩家查询、存档诊断、错误日志和退出验收。
- 不公开后台入口可以减少 V1 的公网攻击面，也不新增云资源消耗。

## 执行范围

- 移除仅用于公网静态部署的生产环境文件、构建命令、产物检查脚本和网关配置说明。
- README 固定为 `npm run dev:cloud` 本地使用方式。
- 不修改现有页面、管理 API、Cookie 安全属性、RBAC 或数据库。
- 正式公网部署后置到确有多人异地使用需求时再评估。

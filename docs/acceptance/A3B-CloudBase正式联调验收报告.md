# A3B CloudBase 正式联调验收报告

## 验收结论

V1 简易管理后台已通过 CloudBase 正式服务联调。管理员可以登录并读取玩家列表、玩家详情、微信资料和云存档诊断，退出后会话失效；页面只保留当前版本需要的玩家管理入口。

## 真实接口验收

- 登录：`POST /admin/v1/auth/login` 返回 200，成功签发会话 Cookie。
- 会话：Cookie 保留 `HttpOnly` 与 `SameSite=Strict`；本地代理仅为回环 HTTP 调试移除 `Secure`。
- 当前管理员：`GET /admin/v1/auth/me` 返回 200。
- 玩家列表：`GET /admin/v1/players` 返回 200，正式环境当前可读取 1 名玩家。
- 玩家详情：`GET /admin/v1/players/:playerId` 返回 200，微信资料与云存档摘要可读取。
- 退出：`POST /admin/v1/auth/logout` 返回 200。

## 页面验收

- 登录页账号、密码和登录流程正常，成功后跳转到 `/players`。
- 导航只显示“玩家管理”，不再显示仪表盘、接口状态、接口文档和通知入口。
- 玩家列表可以显示平台、状态、最近登录时间、存档 revision，并能通过“详情”进入玩家详情。
- 玩家详情可以显示基础资料、微信昵称、资料更新时间和云存档摘要。
- 云存档诊断可以显示当前版、上一版和 `user` 字段差异，不展示内部 hash。
- 退出后返回登录页。

# A7C 公告状态“启用/停用”术语验收报告

## 验收范围

- 公告列表状态筛选。
- 公告列表行内状态设置。
- 公告新增与编辑弹窗状态设置和说明文案。
- 原有接口值与线上数据兼容性。

## 验收结果

- 管理后台不再向管理员展示“草稿/已发布”或“隐藏/显示中”，统一显示“停用/启用”。
- `draft` 数据显示为“停用”，`published` 数据显示为“启用”。
- 管理后台提交的接口值保持不变，不需要迁移已有公告或重新部署后端。
- 启用公告仍受平台和生效时间控制；自动弹出仍为独立配置。

## 结论

公告状态术语已与实际开关语义保持一致，并保留现有接口和数据兼容性。

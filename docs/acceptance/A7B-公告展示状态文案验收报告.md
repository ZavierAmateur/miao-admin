# A7B 公告展示状态文案验收报告

日期：2026-09-21

## 审计结论

- 公告的 `draft/published` 字段实际控制玩家是否能看到公告，不是一次性的“发布流程”。
- 原“草稿/已发布”容易让管理员误解，因此只调整管理后台展示文案，不修改后端枚举和数据库数据。

## 执行内容

- `draft` 在管理后台统一显示为“隐藏”。
- `published` 在管理后台统一显示为“显示中”。
- 筛选项、列表表头、列表快速修改、编辑表单和底部说明均使用“展示状态”。
- 接口仍提交 `draft/published`，不需要数据库迁移，也不影响现有两条测试公告。

## 验收结论

- `npm run lint`：通过。
- `npm run typecheck`：通过。
- `npm test`：通过。
- `npm run build`：通过。
- `git diff --check`：通过。

结论：管理后台公告状态含义已改为玩家视角的“隐藏/显示中”，界面语义与实际行为一致。
